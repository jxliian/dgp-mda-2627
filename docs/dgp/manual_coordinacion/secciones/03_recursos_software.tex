\section{Recursos Software de Desarrollo}

La aplicación se desarrollará principalmente en \textbf{Flutter}. Trabajaremos con el \textbf{IDE de Flutter} por las facilidades que nos brinda a la hora de hacer tests unitarios e interfaces personalizables en tiempo de ejecución.

\subsection{Ecosistema y Herramientas de Desarrollo}
\begin{itemize}[leftmargin=*]
  \item \textbf{Framework de Desarrollo Frontend:} \textbf{Flutter SDK (Dart)}. Permite generar aplicaciones nativas multiplataforma desde un único código fuente, asegurando un rendimiento fluido en las tabletas Android del colegio y compatibilidad web para pizarras digitales.
  \item \textbf{Entorno de Desarrollo (IDE de Flutter):} \textbf{Visual Studio Code / Android Studio} con las extensiones oficiales de Flutter y Dart. Ofrece:
    \begin{itemize}
      \item \textit{Hot Reload} y \textit{Hot Restart} para modificar y personalizar componentes gráficos y estilos visuales en tiempo de ejecución de manera instantánea.
      \item Suite integrada para ejecución automatizada y depuración de pruebas unitarias (*Flutter Test*).
      \item \textit{Flutter DevTools} para análisis de rendimiento, inspección del árbol de widgets y perfiles de memoria.
    \end{itemize}
  \item \textbf{Backend y API REST:} \textbf{Node.js con Express y TypeScript}, aportando tipado seguro, arquitectura desacoplada y alta escalabilidad en la gestión de servicios web.
  \item \textbf{Persistencia y Base de Datos:} \textbf{PostgreSQL} gestionado a través de \textbf{Prisma ORM}, empaquetado en contenedores Docker para reproducibilidad total de los entornos de ejecución.
  \item \textbf{Servicios en Tiempo Real:} \textbf{WebSockets / Socket.io} para el intercambio instantáneo de mensajes en el chat tutor--estudiante y la sincronización de estados de tareas.
  \item \textbf{Catálogo de Apoyos Visuales:} Catálogo oficial de pictogramas de \textbf{ARASAAC} (licencia Creative Commons) para comunicación aumentativa.
  \item \textbf{Diseño UX/UI:} \textbf{Figma} para la confección y testeo de wireframes accesibles previos a la fase de programación.
\end{itemize}
