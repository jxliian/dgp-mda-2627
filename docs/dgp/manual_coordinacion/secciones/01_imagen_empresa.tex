\section{Imagen de Empresa}

\subsection{Identidad Corporativa: CLENCH Software Development}
El equipo de trabajo opera bajo la identidad \textbf{CLENCH Software Development}. Esta iniciativa combina el aprendizaje con el desarrollo de software de calidad para promover la responsabilidad social y la inclusión de personas en situación de vulnerabilidad.

\begin{center}
  \includegraphics[width=6.0cm]{images/logo_clench.png}
\end{center}

\begin{itemize}[leftmargin=*]
  \item \textbf{Denominación Oficial:} CLENCH Software Development.
  \item \textbf{Lema y Propósito:} \textit{«Tecnología accesible para potenciar la autonomía personal»}.
  \item \textbf{Misión:} Diseñar, implementar y validar soluciones digitales accesibles,que faciliten la rutina diaria de estudiantes con Necesidades Específicas de Apoyo Educativo (NEAE).
  \item \textbf{Valores:}
  \begin{enumerate}
    \item \textbf{Accesibilidad y Empatía:} La persona usuaria (estudiantes PTVAL y profesorado de la Fundación Purísima Concepción) es el núcleo de cada decisión de diseño.
    \item \textbf{Calidad:} Compromiso con el código limpio, análisis estático, cobertura de pruebas y estabilidad.
    \item \textbf{Transparencia y Coordinación:} Comunicación fluida, reparto equitativo de esfuerzo y sinceridad en la estimación de plazos y riesgos.
  \end{enumerate}
\end{itemize}
