\section{Manual de Accesibilidad y Calidad}

El Gestor de Accesibilidad y el Gestor de Calidad se encargarán conjuntamente de elaborar un manual de accesibilidad que proporcione al resto del equipo los conocimientos necesarios para diseñar una aplicación accesible y satisfactoria para sus usuarios. A continuación se presenta dicho manual:
