# Registro y Control de Dedicación Horaria Individual (CLENCH)

Este directorio centraliza las plantillas y el seguimiento de la **dedicación horaria individual** de todos los miembros del equipo **CLENCH Software Development** para las asignaturas **Dirección y Gestión de Proyectos (DGP)** y **Metodologías de Desarrollo Ágil (MDA)**.

---

## 1. Normas de Imputación Horaria (Manual de Coordinación)
- **Periodicidad:** Cada integrante debe registrar semanalmente las horas reales invertidas en cada tarea.
- **Transparencia y honestidad:** Las horas deben reflejar el esfuerzo verídico dedicado a reuniones, diseño, desarrollo, pruebas y documentación.
- **Supervisión:** El **Coordinador** y el **Gestor de Calidad** revisarán periódicamente la uniformidad y el balance del esfuerzo del equipo, detectando sobrecargas o desviaciones respecto a la estimación inicial.
- **Categorías estándar de imputación:**
  1. `Reuniones`: Sesiones internas de equipo, entrevistas con el cliente (Colegio Purísima Concepción) y tutorías docentes.
  2. `Requisitos`: Análisis de necesidades, especificación de requisitos, historias de usuario y backlog.
  3. `Diseño y Arquitectura`: Diagramas UML (Visual Paradigm), diagramas de base de datos y modelado de datos.
  4. `Usabilidad y Accesibilidad`: Auditorías WCAG 2.1 AA, adaptación cognitiva, pictogramas ARASAAC, pruebas de contraste y lectores de pantalla.
  5. `Desarrollo`: Programación frontend y backend en Flutter/Dart, integración de almacenamiento y lógica de negocio.
  6. `Pruebas`: Tests unitarios, tests de widgets, pruebas de integración y validación de usuario.
  7. `Documentación y Gestión`: Redacción de memorias, manuales de coordinación, actas y gestión en Jira/GitHub.
