# Scripts de Soporte y Automatización (`scripts/`)

En esta carpeta se alojarán los scripts auxiliares para el ciclo de vida del proyecto:
- Scripts de inicialización y preparación de datos iniciales / semillas de prueba (mock data de estudiantes, tareas y pictogramas).
- Scripts para verificación local de linters, formateo y validadores de accesibilidad.
- Automatizaciones para exportación o empaquetado de entregables.
